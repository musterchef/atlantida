# Registrazioni FIT del viaggio

Questa cartella contiene gli originali FIT delle tappe 1–7 e 9–12,
con i nomi dei file esportati da Strava. La tappa 8 non è presente.

`duplicati/` conserva la seconda copia della tappa 6, identica secondo
SHA-256 all'originale nella cartella principale. Il comando di analisi
delle tappe legge solo i file direttamente nella cartella indicata.

Lettura, selezione degli intervalli e comandi sono descritti in
[ANALISI-PERCORSO.md](../doc/ANALISI-PERCORSO.md#sorgenti-fit-e-gpx).
